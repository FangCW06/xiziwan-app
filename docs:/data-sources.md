# 資料來源整理

## 主要資料平臺

### 1. 氣象資料開放平臺(opendata.cwa.gov.tw)
- 提供天氣特報(豪雨/強風/雷雨)、紫外線指數、天氣預報
- **需要會員帳號 + API 授權碼**才能串接
- 有線上 API 說明文件(swagger),可先在網頁上測試查詢參數與回傳格式:
  https://opendata.cwa.gov.tw/dist/opendata-swagger.html

**申請流程:**
1. 至 opendata.cwa.gov.tw 註冊會員(只需 email)
2. 收信驗證
3. 登入後於會員專區取得授權碼(格式如 `CWA-XXXX-XXXX-XXXX-XXXX-XXXXXXXXXXXX`)
4. 查詢網址格式:
   ```
   https://opendata.cwa.gov.tw/fileapi/v1/opendataapi/{資料代碼}?Authorization={授權碼}&format={格式}
   ```
   格式可選 XML、CAP、JSON、ZIP、KMZ 等,依各資料集而定

### 2. 海象環境資訊平台(ocean.cwa.gov.tw)
- 供應自 2000 年以來中央氣象署各潮位站及浮標站的海象觀測數據
- 涵蓋:潮位、波浪、海面風、海流、海溫
- 提供 GIS 電子地圖與篩選功能,方便找到目標地區觀測站
- 「航行海象 SAFE SEE」子平台已有現成警示燈號邏輯可參考(大潮/暴潮/長浪/巨浪/海溫寒害等分級)

## 西子灣專屬資料(重點發現)

中央氣象署**已有西子灣專屬海水浴場頁面**(PID=A008),整合以下資料:
- 溫度、體感溫度、相對濕度
- 時雨量、日出日落
- 72 小時預報 + 一週預報(含溫度曲線、體感溫度曲線)
- **逐三小時海象預報**(浪高、浪向,採八方位)
- **潮汐預報**(潮位曲線圖,單位 cm,可切換基準面)

對應潮位站:**高雄市鼓山**(西子灣所在行政區),官方另有「高雄市鼓山未來30天潮汐預報」資料。
潮汐預報分區則屬於「安平高雄沿海」。
