# 海況安全 App(暫名)— 西子灣 MVP 專案

## 產品一句話
一個用「浮動的狗+動態海浪」把海況(潮汐、風速、波高、天氣特報)轉成紅黃綠三色燈號的水上安全 App,鎖定一般人(非玩家/非專業)的快篩需求。

## 核心概念
- **不分活動類型**,只判斷「整體海況適不適合下水」
- 三色燈號:綠(可下水)/ 黃(需注意)/ 紅(危險,勿下水)
- 視覺化重點:海浪的**波幅與流動速度**隨危險等級增加,狗狗角色浮在浪的交界線上隨波浪同步移動
- 底部按鈕文字隨等級變化語氣(如:Enjoy your play → Be aware of your surroundings → Do not enter the water)
