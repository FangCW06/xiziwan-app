# 落地路徑

從資料驗證到上架的七步:

1. **驗證資料與閾值來源**——聯繫海洋運動相關單位或參考既有公開安全標準,確保紅黃綠燈判斷邏輯有依據,而非自訂
2. **鎖定第一個測試地點**——西子灣(已選定,原因見 README)
3. **做出資料串接的技術原型**——申請 API 金鑰,寫小程式把潮汐、波高、風速、特報資料串起來
4. **設計並測試視覺化+動畫**——狗+海浪概念做成可互動原型,讓非玩家的一般人實際看過測試理解度
5. **加上清楚的免責與資訊來源標示**——送審前必做,保護自己的關鍵一步
6. **用 Claude Code 做出 MVP**——技術方向(資料來源、分級邏輯、視覺設計)清楚後執行效率最高
7. **小範圍測試後再上架**——身邊會去海邊的朋友/家人實際使用,收集回饋調整後再送審 App Store

## 目前所在階段
第 2-3 步之間:已選定西子灣為測試地點,準備申請 CWA 開放資料平臺帳號、取得 API 金鑰。
