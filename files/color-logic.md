# 三色分級判斷邏輯(草稿,閾值待驗證)

## ✅ 已確認的官方標準

### 1. 台灣官方海灘旗幟標準(全國通用,各縣市政府文宣均引用)
出自「水域遊憩活動警示旗幟」規範(參考澳洲海浪救生協會 Surf Life Saving Australia 圖例):

| 旗幟 | 意義 |
|------|------|
| 🟩 綠色三角旗 | 水域開放,適宜游泳 |
| 🟨 黃色三角旗 | 當心!水域狀況不佳,游泳特別注意安全(不善泳者及老幼婦孺須特別小心) |
| 🟥 紅色三角旗 | 水域關閉,危險!請勿下水 |
| 🚩 上紅下黃四角旗 | 救生員守望範圍,可在兩支旗之間游泳 |

這與本產品原本設計的三色分級(綠/黃/紅)概念一致,可作為 App 顏色代表意義的官方對應基礎。

**⚠️ 重要落差**:此標準只定義「顏色代表什麼」,**沒有定義「浪高/風速多少換算成哪個顏色」**——旗幟懸掛由現場救生組長依經驗判斷,是人的判斷,不是公式。App 的自動判斷是用數據去逼近這個人為判斷,需要在免責聲明中誠實說明:「本 App 顏色為根據氣象資料自動估算,可能與現場救生員實際判斷不同,請以現場旗幟為準」。

### 2. 極端等級的官方數值門檻(可直接作為紅色上限保底值)
- **巨浪告警**:風浪或湧浪浪高超過 **6 公尺**,即為「巨浪」(氣象署颱風等級警戒定義)
- **陸上強風特報**:平均風 **6 級以上**(蒲福風級)或陣風 **8 級以上**

這兩個是颱風等級的極端門檻,可直接作為「絕對紅色」的保底值,但不足以涵蓋日常的細緻分級(例如平日浪高 1-2 公尺時該算黃還是綠)。

## 設計原則
採用「**任一硬指標觸發即降級**」的邏輯,而非加權平均——安全類產品寧可保守,不做「數值互相抵銷」的平均計算。

## 判斷架構(定案版)

```
若符合以下任一條件 → 紅色(危險,勿下水)
- 豪雨特報 / 強風特報 / 雷雨特報 生效中
- 風級達 6 級以上(對應氣象署陸上強風特報門檻,國際標準海面已達「大浪開始出現」)
- 浪高超過 3 公尺(對應蒲福6級平均浪高;超過6公尺為官方巨浪告警等級,絕對紅色)
- 颱風警報生效中
- 現在時間非開放時段(09:00~日落,見「開放時間邏輯」)

否則,若符合以下任一條件 → 黃色(需注意)
- 風級達 4-5 級(小浪拖長至中浪,浪花已開始飛濺)
- 浪高介於 1-2 公尺
- 處於潮汐交替時段(滿潮/乾潮前後)
- 距離日落不到 1 小時(即將進入非開放時段)

否則(風級 0-3,浪高 1 公尺以下) → 綠色(適合下水)
```

**分界點依據說明**:黃→紅的分界訂在風級6級,並非自訂,而是與氣象署「陸上強風特報」官方發布門檻一致,是目前最具公信力的分界依據。

## 重要提醒(來自安全責任討論)
- **日常級別的閾值不可憑感覺自訂**,建議路徑:
  1. 先用蒲福風級官方描述(每級對應的海況文字說明)做合理估算
  2. 官方巨浪告警(6m)、強風特報(6級/陣風8級)作為紅色上限保底
  3. 若仍不夠精確,可考慮聯繫高雄市政府海洋局做校準(非必要起點,是加分動作)
- 這是產品可信度的地基,也是免責聲明能站得住腳的前提
- App 內須明確標示兩件事:
  1. 「本 App 僅供參考,實際下水請以現場狀況及救生員指示為準」
  2. 「顏色分級為根據氣象資料自動估算,可能與現場實際旗幟不同」

## 開放時間與日落倒數邏輯

西子灣沙灘開放時間為**上午9時至當天日落**,非固定時段,需串接 A-B0062-001(日出日沒時刻資料集)取得當天精確日落時刻。

### 判斷架構
```
若 現在時間 < 09:00
  → 顯示「尚未開放」

否則若 現在時間 > 當天日落時刻
  → 顯示「已過開放時間」,即使海況數字正常也要標示現場無救生員/非開放時段

否則若 距離日落 < 1 小時
  → 正常套用紅黃綠燈邏輯,但額外顯示「日落倒數提醒」(例如:「距離日落還有 45 分鐘,建議準備上岸」)

否則
  → 正常套用紅黃綠燈邏輯,不特別提示時間
```

### 設計理由
- 比起單純的「開放/已過期」二元判斷,漸進式的日落倒數提醒(尤其是日落前1小時)更符合產品「有溫度」的調性,提前提醒使用者準備上岸,而不是讓使用者一到日落就突然被告知「已關閉」
- 日落時刻全年變動(夏天晚、冬天早),不可寫死固定時間
