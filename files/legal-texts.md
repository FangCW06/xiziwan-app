# 法律文件文字(草稿,供直接使用)

⚠️ 我不是律師,以下內容是根據政府條款要求與業界慣例整理的草稿。免責聲明部分建議直接使用;隱私政策部分因涉及使用者資料保護法規,正式上架前建議找律師看過一次。

---

## 一、資料來源顯名聲明(法律要求,必須放,不是選項)

根據「政府資料開放授權條款–第1版」規定,使用政府開放資料**必須**用附件指定格式標示來源,沒有標示視同未取得授權。標準格式如下:

> 提供機關／單位 [年份] [開放資料釋出名稱與版本號]
> 此開放資料依政府資料開放授權條款(Open Government Data License)進行公眾釋出,使用者於遵守本條款各項規定之前提下,得利用之。
> 政府資料開放授權條款:https://data.gov.tw/license

**套用到你的 App,建議放在「關於/資料來源」頁面,寫成這樣:**

```
本 App 使用以下中央氣象署開放資料:

・交通部中央氣象署 [2026] 潮汐預報(F-A0021-001)
・交通部中央氣象署 [2026] 海象監測資料-48小時浮標站與潮位站海況監測資料(O-B0075-001)
・交通部中央氣象署 [2026] 日出日沒時刻資料(A-B0062-001)

此開放資料依政府資料開放授權條款(Open Government Data License)進行公眾釋出,
使用者於遵守本條款各項規定之前提下,得利用之。
政府資料開放授權條款:https://data.gov.tw/license
```

年份記得每年更新成當年,或改成動態抓取當下年份。

## 二、免責聲明(改寫為「幫助使用者順利安排行程」的實用版本)

你說得對——與其把這段寫成冷冰冰的法律擋箭牌,不如順著產品「讓想去玩的人更方便上手」的目的,把它設計成**首次開啟時的引導頁**,同時給出真正有用的官方連結,讓使用者一站買齊所有需要知道的事。草稿如下:

```
【出發前,你需要知道】

本 App 的海況燈號,是根據中央氣象署開放資料自動估算,
幫助你快速判斷「今天適不適合去西子灣玩水」——
但這是輔助參考,不是最終答案,以下幾件事務必留意:

・西子灣沙灘開放時間:每日上午9時至當天日落
  (非開放時段沒有救生員駐點,請避免此時段下水)

・本 App 顏色僅供參考,可能與現場實際狀況不同,
  請以現場公告及實際海況為準

・海象資料可能有延遲或短暫中斷,App 會標示資料
  「最後更新時間」,請留意數據是否夠新

・下水前建議先評估自身泳技與體能狀況

【更多官方資訊】
・中央氣象署西子灣天氣頁面:[連結]
・高雄市政府海洋局水域遊憩活動公告:[連結]
・國立中山大學西子灣沙灘開放須知:[連結]

【緊急狀況】
如遇緊急狀況請立即撥打 119(消防/救護)或 118(海巡署)

──
中央氣象署對開放資料之準確性、完整性不作保證;
使用本 App 所生之任何損失,開發者與資料提供機關均不負賠償責任。
```

**建議的官方連結(已幫你查好,直接放入即可):**
- 中央氣象署西子灣天氣頁面:`https://www.cwa.gov.tw/V8/C/L/Beach/Beach.html?PID=A008`
- 高雄市政府海洋局水域遊憩活動公告:`https://kcmb.kcg.gov.tw/cp.aspx?n=C27F055F98DA8C5B`
- 國立中山大學西子灣沙灘開放須知(PDF):`https://property-oga.nsysu.edu.tw/var/file/102/1102/img/540654205.pdf`

**設計上的建議**:這段文字不要一次全部塞給使用者看(容易被跳過不讀),可以拆成兩層——
1. **首次開啟**:只顯示最關鍵的 3-4 點(開放時間、燈號僅供參考、緊急電話),輕量、不嚇跑人
2. **「關於本App」頁面**:放完整版,包含官方連結與正式免責條款,給想深入了解的人查

法律最低要求的部分(中央氣象署免責聲明模板那段)還是要保留在完整版裡,但不用放在使用者第一次打開時就看到的畫面。

## 三、隱私政策(基礎版)

由於本 App **僅提供西子灣單一地點**,不需要偵測使用者當下位置,因此**不需要定位權限**,隱私政策可以大幅簡化:

```
【隱私政策】

本 App 重視使用者隱私,說明如下:

1. 定位資訊
   本 App 目前僅提供西子灣單一地點之海況資訊,
   不需要、也不會取用您的裝置定位權限。

2. 資料蒐集
   本 App 不要求註冊帳號,不主動蒐集您的個人身分資訊。

3. 第三方資料
   本 App 顯示之海況資訊來自中央氣象署公開資料,
   非使用者個人資料。

4. 聯絡方式
   若對隱私權有任何疑問,請透過 [你的聯絡email] 與我們聯繫。

最後更新日期:[上架前填入日期]
```

**放置位置:**
- App 內的「關於」頁面
- App Store Connect 後台仍需填一個外部網頁連結(Apple 規定即使內容簡單,也要有公開網址),可用 Notion 公開頁面或 GitHub Pages 免費產生

**之後若擴充多地點,才需要加回定位權限說明**,現階段先保持簡單。
