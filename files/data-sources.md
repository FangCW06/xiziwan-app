# 資料來源整理

## 主要資料平臺

### 1. 氣象資料開放平臺(opendata.cwa.gov.tw)
- 提供天氣特報(豪雨/強風/雷雨)、紫外線指數、天氣預報
- **需要會員帳號 + API 授權碼**才能串接
- 有線上 API 說明文件(swagger),可先在網頁上測試查詢參數與回傳格式:
  https://opendata.cwa.gov.tw/dist/opendata-swagger.html

**申請流程:**
1. 至 opendata.cwa.gov.tw 註冊會員(只需 email)
2. 收信驗證
3. 登入後於會員專區取得授權碼(格式如 `CWA-XXXX-XXXX-XXXX-XXXX-XXXXXXXXXXXX`)
4. 查詢網址格式:
   ```
   https://opendata.cwa.gov.tw/fileapi/v1/opendataapi/{資料代碼}?Authorization={授權碼}&format={格式}
   ```
   格式可選 XML、CAP、JSON、ZIP、KMZ 等,依各資料集而定

### 2. 海象環境資訊平台(ocean.cwa.gov.tw)
- 供應自 2000 年以來中央氣象署各潮位站及浮標站的海象觀測數據
- 涵蓋:潮位、波浪、海面風、海流、海溫
- 提供 GIS 電子地圖與篩選功能,方便找到目標地區觀測站
- 「航行海象 SAFE SEE」子平台已有現成警示燈號邏輯可參考(大潮/暴潮/長浪/巨浪/海溫寒害等分級)

## 西子灣專屬資料(重點發現)

中央氣象署**已有西子灣專屬海水浴場頁面**(PID=A008),整合以下資料:
- 溫度、體感溫度、相對濕度
- 時雨量、日出日落
- 72 小時預報 + 一週預報(含溫度曲線、體感溫度曲線)
- **逐三小時海象預報**(浪高、浪向,採八方位)
- **潮汐預報**(潮位曲線圖,單位 cm,可切換基準面)

對應潮位站:**高雄市鼓山**(西子灣所在行政區),官方另有「高雄市鼓山未來30天潮汐預報」資料。
潮汐預報分區則屬於「安平高雄沿海」。

## ✅ 已實測成功的資料集(MVP 確定採用)

### 1. F-A0021-001(潮汐預報)
- LocationName:**高雄市鼓山區**(縣市+鄉鎮需完整合併,不能只寫「鼓山區」)
- 提供:滿潮/乾潮時刻、潮高(三種基準面)、大潮/中潮/小潮
- 詳細欄位說明見 `data-samples/tide-sample.md`

### 2. O-B0075-001(48小時浮標站與潮位站海況監測資料)
這個資料集需要用 **StationID** 查詢(不是地名),而且**不同測站提供的欄位不一樣**,實測發現需要**兩個測站互補**:

| StationID | 測站名稱/屬性 | 提供的資料 | 實測有值比例 |
|-----------|--------------|-----------|-------------|
| **C4P01** | 高雄潮位站(鼓山區,座標與西子灣資料一致) | TideHeight、TideLevel、SeaTemperature | 潮高 48/49、海溫 48/49 |
| **COMC08** | 彌陀資料浮標(高雄市彌陀區外海,水深23m) | WaveHeight、WaveDirection、WavePeriod、WindSpeed、WindScale(蒲福風級)、StationPressure | 各欄位約 35/49 |

**⚠️ 潮位站 ≠ 浮標站**:C4P01 完全沒有 WaveHeight/WindSpeed 欄位(潮位站沒裝這些感測器);COMC08 完全沒有 TideHeight/SeaTemperature。這是政府資料的現實限制,MVP 階段用「兩站互補」處理,之後若要更精準可以再找離西子灣更近的浮標站。

**⚠️ 最新一筆不一定有值**:實測發現最新時間戳記的那筆資料,欄位常常是 "None"(可能剛好斷線或還沒回傳),但往前幾筆是正常的。抓資料時要用「**由新到舊,找第一筆有效值**」的邏輯,不能直接抓時間最新那筆。

### 查詢方式
```
潮汐: https://opendata.cwa.gov.tw/fileapi/v1/opendataapi/F-A0021-001?Authorization={授權碼}&format=JSON&LocationName=高雄市鼓山區
海況: https://opendata.cwa.gov.tw/fileapi/v1/opendataapi/O-B0075-001?Authorization={授權碼}&format=JSON&StationID=C4P01
海況: https://opendata.cwa.gov.tw/fileapi/v1/opendataapi/O-B0075-001?Authorization={授權碼}&format=JSON&StationID=COMC08
```

### 蒲福風級(Beaufort Scale)的價值
O-B0075-001 的 WindScale 欄位就是蒲福風級,這是國際通用的風力分級標準(0-12級,各級有對應的海況描述),用這個作為紅黃綠燈判斷依據,比自己訂風速數字閾值更有公信力與國際標準支撐。

## 3. A-B0062-001(日出日沒時刻-全臺各縣市年度逐日日出日沒時刻資料)
- 類別:天文
- 提供全臺各縣市**逐日**日出日沒時刻,涵蓋全年,另含民用曙光、方位、仰角等進階資訊
- 用途:西子灣沙灘開放時間為「上午9時至當天日落」,日落時刻全年變動(夏天晚、冬天早),需用此資料集才能精確判斷,不能寫死固定時間
- 查詢方式同其他資料集,透過 opendata.cwa.gov.tw + 授權碼取得
